# AI Maze Solver

A maze-solving project that visualizes search algorithms on a grid, with a Node.js backend and a JavaScript frontend.

## Structure

```
BackEnd/             Node.js service (tile model and solver logic)
FrontEnd/maze_solver Frontend visualizer
Test Data.xlsx       Test data used while evaluating the solvers
```

## Run locally

```bash
# Backend
cd BackEnd && npm install && node index.js

# Frontend
cd FrontEnd/maze_solver && npm install && npm run dev
```
